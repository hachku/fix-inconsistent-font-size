# Vessi-inspired mobile landing page

This project recreates the feel of the Vessi mobile landing page shown in the reference screenshots. It uses a static `index.html` and `styles.css` with Google Fonts and Unsplash-sourced photography to approximate the layout and typography of the promo bar, category carousel, hero section, product grid, and feature story.

## Quick start
1. Open `index.html` in your browser to view the page.
2. For local development, run a simple static server (e.g., `python -m http.server 8000`) and visit `http://localhost:8000`.
